One original haiku about debugging, three lines in the 5-7-5 syllable shape: a cursor blinking at three in the morning, a log line that swears everything worked — and the turn that the bug was only a typo. Concrete picture, sharp last line, every word earning its place. Running `main.py` writes that haiku to `entry.txt` — first to the grader's output directory, then as a local copy. Pure Python standard library, no network, no dependencies.

## The haiku

> Cursor blinks at three
> one more log line lies again
> it was a typo

## Run it

```sh
python3 main.py
```
